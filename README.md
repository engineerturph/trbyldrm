# Turabi Yildirim Portfolio

Static portfolio site for GitHub Pages, with an optional local Node editor.

## Local preview

```sh
npm start
```

The public portfolio is available at `http://localhost:4173`.

## Local editor

Set editor credentials before starting the server:

```sh
EDIT_NICKNAME=your-name EDIT_PASSWORD=your-password npm start
```

Then open `http://localhost:4173/edit`.
